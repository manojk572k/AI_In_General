1. What an LLM Is

LLM = Large Language Model

It is a neural network trained on huge text data that can:

generate text

answer questions

write code

summarize information

Examples:

OpenAI GPT models

Google Gemini

Anthropic Claude

Important idea:

LLMs do not know facts like a database.
They predict the next word based on patterns.

Example:

JavaScript is a ______ language

Model predicts → programming

3. What Tokens Are

AI models do not read full sentences.

They read tokens.

Example sentence:

React hooks make state management easier

Tokens might be:

React
hooks
make
state
management
easier

Each token costs API usage.

So developers must manage:

token limits

response size

cost

5. Your First AI API Request

We will call an AI model using Node.js.

Using:

OpenAI API

Step 1 Install package
npm install openai
Step 2 Create file
ai-test.js
Step 3 Code Example
import OpenAI from "openai";

const openai = new OpenAI({
  apiKey: "YOUR_API_KEY"
});

async function testAI() {

  const response = await openai.chat.completions.create({
    model: "gpt-4.1-mini",
    messages: [
      {
        role: "user",
        content: "Explain JavaScript closures in simple words"
      }
    ]
  });

  console.log(response.choices[0].message.content);
}

testAI();

Run:

node ai-test.js

You will see an AI explanation printed.
